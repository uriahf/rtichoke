# Creating subtitle for ggplot2

Creating subtitle for ggplot2

## Usage

``` r
create_subtitle_for_ggplot(
  probs_names,
  color_values = c("#5BC0BE", "#FC8D62", "#8DA0CB", "#E78AC3", "#A4243B")
)
```

## Arguments

- probs_names:

  the names of the probs

- color_values:

  color palette

## Examples

``` r
if (FALSE) { # \dontrun{
create_subtitle_for_ggplot(
  probs_names = c(
    "First Model", "Second Model", "Third Model"
  )
)
} # }
```
