# Creating Reference Lines Data Frame

Creating Reference Lines Data Frame

## Usage

``` r
create_reference_lines_data_frame(
  curve,
  prevalence = NA,
  color = NA,
  plotly = FALSE,
  multiple_pop = FALSE,
  performance_data = NULL
)
```

## Arguments

- curve:

  the specified curve for the reference lines

- prevalence:

  the prevalence of the outcome

- color:

  the required color

- plotly:

  should the reference lines data frame be competible with plotly

- multiple_pop:

  should the reference lines data frame should be adjusted to multiple
  populations
