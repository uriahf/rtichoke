# Rendering and Formatting gt

Rendering and Formatting gt

## Usage

``` r
render_and_format_gt(
  performance_data,
  main_slider,
  perf_dat_type,
  prevalence,
  color_values
)
```

## Arguments

- performance_data:

  an rtichoke Performance Data

- prevalence:

  the prevalence of the populations

- color_values:

  color palette
