# rtichoke: Interactive Evaluation of Binary Prediction Models

Interactive tools for evaluating binary prediction-model performance.
Provides visualizations and summaries for receiver operating
characteristic and precision-recall curves, gains and lift charts,
decision curves, calibration, confusion matrices, model metrics, and
related performance reports.
